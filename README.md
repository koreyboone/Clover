# Clover

Clover is a responsive web proof of concept for a parent-managed household routine and a restricted shared display. The current app is in [`app/`](app/).

See the [app setup, operations, deployment, and data-handling guide](app/README.md) before running it. This is an early proof of concept, not the complete routine/rewards product: scheduled runs, rewards, household export/restore, and a supported household-deletion workflow are not implemented.
